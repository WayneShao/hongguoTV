# 按记录载入触发自动同步

用户要求：增加自动同步开关和同步间隔；默认间隔五分钟，开启后在首页接着看、继续观看和最近观看载入记录时，距上次同步超过间隔才同步一次。

- 开关默认关闭，间隔提供 1、5、10、15、30、60 分钟，默认 5 分钟。设置保存在本机，重启保留。
- 复用已验证的进度合并及上传队列；实际集序、看完状态和播放位置决定进度，不按时间戳覆盖领先进度。
- 自动模式只合并当前账号已归属的本地记录和云端独有记录；未归属访客记录、其他账号记录和删除抑制记录跳过。手动合并仍可明确纳入访客记录。
- 首页接着看、接着看的更多列表、最近观看页面构建或恢复时检查。账号及本机记录尚未就绪时不启动，就绪后若仍在上述页面再检查一次。后台、播放器、设置和其他片单不触发；没有定时轮询。
- 同一账号的启动时间持久化，自动启动后失败也按间隔限频，防止连续页面重载反复请求。首次开启且该账号没有时间记录时，下一次符合条件的载入立即同步；修改间隔后立即使用新的间隔判断。手动同步成功重置当前账号的间隔，手动失败不修改已有时间，手动按钮不受间隔限制。忙碌或未就绪而拒绝启动不消耗间隔。时钟回拨允许一次重新计时。
- 只有一个合并任务，手动和自动共用并发控制。切换账号、销毁 Activity 时沿用现有身份和生命周期保护。设置关闭阻止后续自动任务，已接受的合法队列操作保持现有持久化语义。
- 自动合并完成后，仅当仍处于前台记录页面才更新卡片，保留当前焦点；不跳页、不弹对话框、不启动或跳转播放。失败等待下次符合间隔的记录载入。

验证：现有定向用例覆盖禁用和五分钟边界、重复载入、失败限频、拒绝启动、重启、账号隔离、回拨、手动重置及迟到回调，以及自动模式访客排除、手动行为保留和 Activity 入口保护。按用户后续要求，不重复完整矩阵或实机自动同步测试；TV / Keyboard 各 38 项定向用例通过，随后构建三个正式签名包并检查发布元数据。只在可能发声的实机测试前静音。
