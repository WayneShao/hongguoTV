# RayNeo X3 Pro implementation plan

Goal: deliver a separately installable native hongguoTV port with complete app-window stereo, native focus navigation and single-decoder video.

Architecture: one logical View tree per window, software bitmap UI duplication, separate OES renderer controlled through Media3 public Surface APIs. Existing content/playback/local library logic remains authoritative.

Tech stack: Kotlin/Java17, Android API26+, Media3 1.8.0, GLES2, Gradle8.14.3.

- [ ] Baseline: selected device identity/boot state, upstream core tests and debug build; preserve evidence under ignored outputs/rayneo.
- [ ] Rendering: RayNeoLayout, RayNeoDialogs, RayNeo notice helper and OES StereoVideoView with explicit bind/unbind lifecycle. Verify geometry and release ownership.
- [ ] Input: window-owned TempleInput and FocusNavigator; pure behavioral tests for source gating, gesture cancellation/double click, target ownership and direction; device tests for live focus.
- [ ] Integration: MainActivity stereo host and surface-less PlayerView, all dialog construction paths, per-eye dimensions and compact layout, local update notice, independent package/label/version and signing.
- [ ] Verification: core/test + app/test + lint + assemble; independent code review; install verified artifact, check boot continuity, UI/window captures and real playback/lifecycle; preserve APK/hash/signature and report physical acceptance separately.

Workers own disjoint renderer/input files; parent owns integration and all device commands. Review design and final implementation with a read-only reviewer. Do not push or publish.
