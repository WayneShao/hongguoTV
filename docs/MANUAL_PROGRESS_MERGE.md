# 合并与自动同步观看进度

当前分支源码在「设置 → 红果账号」提供「合并观看进度」。登录后手动点击；打开账号页面或登录本身不会批量上传登录前的访客记录。

合并先读取云端观看历史和视频进度，并按实际选集目录比较：先比较集数，再比较同一集的明确完成状态和播放位置，不以更新时间决定谁领先。

- 云端领先：更新本机最近观看和续播位置。
- 本地领先：保留本机位置，加入当前账号的待上报队列。
- 两边相同：保留现有记录，避免重复提交。
- 云端没有、本机有：可将未归属账号的访客记录纳入本次手动合并。
- 属于其他账号、已删除，或无法可靠对应选集的记录：跳过。

合并不会跳转正在播放的位置，也不会把跳过的集数标记成已看完。云端接口没有可靠的完成标记时，只采用它提供的集数和位置。

结果中的「待上报」表示已接受的上传工作，不表示已经得到云端回读确认。联网失败会保留待处理工作；两个进度接口分别记录提交结果，重试前重新读取云端。若云端已领先，会取消落后的待处理记录。普通登录仍不自动认领访客历史。

现有云端历史接口返回有限列表；缺少某部剧不代表它在云端被删除。单部剧详情失败会跳过该部；读取任一云端进度来源失败时，本轮不修改本机进度。

「设置」另提供「观看记录自动同步」和「同步间隔」。开关默认关闭，间隔默认 5 分钟，可选 1、5、10、15、30、60 分钟。开启后，载入首页接着看、继续观看集合或最近观看页时，达到当前账号的间隔才进行合并；不会后台定时轮询，也不会改变播放器的位置。

自动同步不纳入尚未归属账号的本机访客记录；手动合并仍可明确纳入。自动同步启动后即记录本次时间，失败也按间隔限频；启动被拒绝不计时。成功的手动合并会重置间隔，手动入口本身不受间隔限制。
